# Blueprint AI 0.8.0

Blueprint AI 0.8.0 deepens deterministic migration orchestration without adding autonomous mutation
authority.

- One ordered pipeline model now composes native tools, established codemods, bounded structural
  edits, rediscovery, typed postconditions, manual boundaries, verification, and exact rollback over
  the existing sealed evolution transaction.
- Versioned authoritative-tool contracts record independently pinned runner and recipe identities,
  integrity, sources, licenses, invoke/redistribute status, immutable images, networking, success
  exits, expected writes, and resource limits.
- Supported migrations now include explicit Rust 2018→2021→2024 edition transitions, conservative
  simple SDK-style .NET projects to net10.0, and minimal setuptools PEP 517 build-system metadata.
- Next.js 14→15→16 exposes a truthfully partial, offline, integrity-pinned official-codemod prefix
  with final-state no-op replay and a sealed lockfile/build/test acceptance record. React 19 remains
  a read-only partial boundary because the separately resolved registry recipe cannot be verified
  before mutation; the upstream invalid `this.refs` output and narrow repair remain permanent tests.
- Reviewed `actions/setup-java` v2–v6 major tags can be pinned to immutable same-major SHAs. No major
  action upgrade is inferred.
- A sealed residual contract defines a possible future agent boundary, but no production agent
  backend exists because the migration corpus did not demonstrate a case that needed one.

All executable migrations remain no-model by default. Supported Rust, .NET, Python, Next.js, and
existing deterministic lanes run with networking disabled after explicit tool-image acquisition.
