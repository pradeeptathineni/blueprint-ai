# Blueprint AI 0.5.0

Blueprint AI now creates and composes local project foundations as well as reviewing existing
repositories. Review and genesis share an evidence-bearing graph of components, scopes, lifecycle,
provenance, and verification.

- Recognize nested and heterogeneous Python, npm, Cargo, Go, and Terraform projects. Apply checks
  to their owning components, distinguish reusable infrastructure from deployments, and reduce
  fixture, generated-code, example, and development-image noise.
- Resolve deterministic names and structured intent into staged generation plans. Compose native
  uv, npm, Vite, and OpenAPI TypeScript providers with CI, service containers, and Dev Containers.
  Verify generated projects before atomic, no-replace publication; retain explicit failure,
  rollback, trust, and incomplete-verification results.
- Ship ten core genesis paths: generic repository; Python library, CLI, and API; TypeScript library
  and CLI; Node API; React; full-stack; and OpenAPI. The validation matrix also covers both backend
  choices, generated API types, and container/CI/Dev Container compositions.
- Reserve bounded, concern-specific source evidence for model contexts and share retrieval work.
  All 54 measured public-corpus contexts contained source snippets. Common genesis and no-model
  review flows require no model credentials.
- Improve public-repository regression results, advisory identity preservation, native tool routing,
  and read-only analysis. Keep scanner caches outside targets and expose unavailable, malformed,
  truncated, or unauthorized checks as incomplete.
- Final release review also corrected malformed manifest/Compose handling, aligned the dry-run
  output with its JSON schema, and removed a hard-coded copyright holder from the MIT template.

This release is ready for the documented local review and genesis scope. Generated foundations are
not production certifications. Cloud generation, remote templates/publication, migrations, semantic
genesis, complete optional-tool coverage, and OS sandboxing remain deferred. Live model judgment was
not evaluated; token measurements are estimates, not billing guarantees. MIT output requires the
project owner to complete the copyright notice.

See [Phase 5 validation](phase-5-validation.md) for measurements and
[project genesis](genesis.md) for supported commands, prerequisites, and limitations.
